Características

Una base para varias generaciones de controles.

ESP32

Control principal con GPIO documentados, alimentación dedicada y firmware editable.

Bluetooth HID

Modo inalámbrico para funcionar como gamepad BLE cuando se usa con batería.

PS1 cableado

Emulación de control digital PS1 con DATA, CMD, ATT, CLK y ACK.

Hardware

Documentación pensada para fabricar y depurar.

El repositorio conserva esquemáticos, PDFs de PCB, BOM, POS, mapeos de GPIO y notas de revisión para mantener trazabilidad entre firmware, placa principal y módulo AutoFire.
